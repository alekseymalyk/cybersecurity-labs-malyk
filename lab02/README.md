# Лабораторна 2 - Захист особистих повідомлень

Програма шифрує текст українською двома шифрами: Цезаря і Віженера.
Ключі взяв зі своїх даних:

- Цезар - зсув 15, це сума цифр моєї дати народження (23.12.2005)
- Віженер - ключ "малик" (прізвище)

Після шифрування програма розшифровує текст назад, показує невелике порівняння
(довжина, скільки всього ключів, яка буква найчастіша) і ламає Цезаря перебором всіх зсувів.

## Як запустити

Треба тільки Python 3, нічого ставити не потрібно.

```
python3 ciphers.py
```

Можна ввести свій текст, або просто натиснути Enter і тоді візьметься мій текст.
Якщо хочете свої ключі, поміняйте `birth_date` і `surname` на початку файлу.

## Що помітив

- латинські букви і цифри програма не шифрує, бо алфавіт тільки український
- у Цезаря всього 32 варіанти, тому перебір знаходить ключ одразу (зсув 15)

Скріни запуску лежать у папці `screenshots/`.

# Lab 02. Захист особистих повідомлень

Консольна програма, яка шифрує текст українською мовою двома класичними шифрами:
шифром Цезаря і шифром Віженера. Ключі беруться з моїх даних:

- Цезар: зсув = сума цифр дати народження 23.12.2005, тобто 15;
- Віженер: ключ = прізвище "малик".

Програма шифрує і розшифровує текст, виводить просте порівняння (довжина, кількість ключів,
найчастіша літера) і ламає шифр Цезаря перебором усіх зсувів.

## Запуск

Потрібен тільки Python 3, бібліотеки не потрібні.

```
python3 ciphers.py
```

Можна ввести свій текст або натиснути Enter, тоді програма візьме текст за замовчуванням.
Дату народження і прізвище можна змінити у змінних на початку файлу `ciphers.py`.

## Скриншоти

У папці `screenshots/`: запуск програми, злом перебором, шифрування введеного тексту.

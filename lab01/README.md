# Lab 01. Аудит власної цифрової безпеки

Проста консольна програма, яка перевіряє пароль: довжину, типи символів, наявність
мого імені, прізвища і дати народження, популярні комбінації. Виводить оцінку від 1 до 10 і рекомендації.

## Запуск

Потрібен тільки Python 3, бібліотеки не потрібні.

```
python3 passcheck.py
```

Далі ввести пароль. Особисті дані задаються змінними на початку файлу `passcheck.py`.

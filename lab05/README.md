# Лабораторна 5 - Захищена електронна пошта

Простий шифратор листів. Ключ роблю з особистих даних: SHA-256 від
пошти + імені + року народження. Текст шифрую симетрично: кожен байт XOR
з потоком байтів, який отримую з SHA-256(ключ + сіль + номер блоку).
Результат записую в base64, щоб його можна було вставити в звичайний лист.

Сіль це 8 випадкових байтів на початку шифротексту. Через неї той самий текст
кожен раз шифрується по-різному.

## Як запустити

Потрібен тільки Python 3 (hashlib і base64 вбудовані):

```
python3 mail_crypt.py
```

Можна ввести свій текст листа або натиснути Enter, тоді візьметься приклад.

Програма:
1. робить ключ з моєї пошти, імені і року народження
2. шифрує лист і зберігає його у `mail/letter1.txt` (заголовки відкриті, текст зашифрований)
3. "одногрупник" розшифровує лист тим самим ключем і відповідає (`mail/letter2.txt`)
4. показує, що з неправильним ключем (рік 2004 замість 2005) лист не прочитати
5. показує, що бачить пошта: від кого, кому і тема видно, текст ні

## Що помітив

- симетричний ключ треба якось передати одногрупнику, тому його краще відправити через PGP
- без солі два листи з однаковим початком мали однаковий початок шифротексту
- ключ з особистих даних легко вгадати, якщо дані відомі, тому в реальному житті треба додавати секретне слово

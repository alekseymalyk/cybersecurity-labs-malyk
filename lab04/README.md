# Лабораторна 4 - Особистий цифровий підпис

Спрощена система цифрового підпису. Документ хешую SHA-256, а хеш "шифрую"
приватним ключем за схемою RSA (маленькі числа, тільки для демонстрації).
Перевірка: розшифровую підпис публічним ключем і порівнюю з хешем документа зараз.

## Ключі з моїх даних

1. SHA-256 від "ПІБ + дата народження + секретне слово"
2. з перших 16 символів хешу беру два числа і шукаю від них прості `p` і `q`
3. `n = p * q`, `e = 65537`, `d` обернене до `e` за модулем `(p-1)*(q-1)`
4. приватний ключ `(d, n)` у `keys/private.key`, публічний `(e, n)` у `keys/public.key`

Підпис: `s = hash ^ d mod n`, перевірка: `s ^ e mod n == hash`.

## Як запустити

Потрібен тільки Python 3 (hashlib вбудований):

```
python3 signature.py
```

Двічі Enter: беру моє секретне слово і документ `documents/dovidka.txt`.

Програма:
1. генерує пару ключів і зберігає у `keys/`
2. підписує документ, підпис кладе у `documents/dovidka.txt.sig` і одразу перевіряє
3. дописує рядок у копію документа (`dovidka_changed.txt`) і перевіряє старим підписом
4. пробує підробити підпис ключем з неправильним секретним словом

## Що помітив

- одна дописана стрічка повністю міняє SHA-256, тому зміну видно одразу
- без секретного слова ключ виходить зовсім інший і підпис не проходить
- це навчальна версія: числа маленькі, а приватний ключ у справжньому житті
  нікуди не викладають, тут він лежить у репо тільки для демонстрації
